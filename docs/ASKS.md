# What I need from Shaun (the running record)

One entry for everything that is waiting on Shaun: a decision, a yes, a login or credential, money or a card, or a physical step only he can do. Write each entry the moment the need comes up (he asked for something to be put on the list, the reviewer or an audit found something, a task is blocked), so it still makes sense days later with no memory of the chat. Remove the entry when he has answered.

Write every entry so a person who has forgotten everything could act on it, in the same shape the reply uses (about 45 to 60 words):
- **It opens with "I need"** and the kind of thing: "I need a decision on ...", "I need your approval to ...", "I need your yes to ...", "I need a login for ...".
- **The subject in plain words**, as a customer would name it (the home page Calculate button), never a code or an ops word.
- **When it came up and what he said or what was found:** "On Nov 3 you said red was a bad colour and it should be blue."
- **His choices and my pick:** "Blue, or leave it red? I'd go blue because it matches the page."
Keep a longer note underneath only for you; the reply uses the short form.
