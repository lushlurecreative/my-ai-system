# Where designs come from (project data, kept on update)

Galleries of curated, top-rated designs. They are references for how good pages look; the project's `pipeline/data/design-catalog.json` (built 2026-10-26, 2,383 entries) lists individual designs from them with their links. One line each: gallery | what it offers.

- Kombai Gallery | https://kombai.com/gallery | 1,380 designs, free, live previews with readable code
- Aceternity UI | https://ui.aceternity.com | 310 components and effects with code
- Landingfolio | https://www.landingfolio.com/inspiration | 320 landing-page designs
- Awwwards | https://www.awwwards.com/websites/ | 155 award-winning sites
- Godly | https://godly.website | 140 curated sites (catalog entries point to recent.design)
- Magic UI | https://magicui.design | 78 components with code

Not used: Land-book and Lapa Ninja (block automated reading), Mobbin (paid login), Refero (login).
